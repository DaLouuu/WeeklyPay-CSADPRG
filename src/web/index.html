Multi-Paradigm Engine Architecture

Go • Kotlin • Ruby • R
Go Engine Procedural / Systems

Strongly typed procedural pipeline with military time parsing and high-throughput execution.

cd src/go && go run main.go
Kotlin Engine OOP / Functional

Object-oriented model utilizing data classes, when-expressions, and null safety guarantees.

cd src/kotlin && kotlinc main.kt -include-runtime -d payroll.jar
Ruby Engine Dynamic OOP

Encapsulated Worker and Workday objects with dynamic dispatch and expressive CLI menus.

cd src/ruby && ruby main.rb
R Engine Vectorized / Stats

Functional implementation with named rate lists, vector math, and statistical reporting.

cd src/r && Rscript main.R
